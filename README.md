# html_golang_sqlite
values from html are stored in sqlite database via golang

step 1:
html page with input of integer values
press button should call a golang function

step 2:
golang function read values of html 
process data internally
save data in sqlite database

step 3:
sqlite database is extended with new values

[step 4:]
read sqlite database to do some additional statistics
