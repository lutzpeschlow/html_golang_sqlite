Wichtige Designfrage
Du solltest jetzt entscheiden, wie du die Scores speicherst:

18 einzelne Spalten: gut für Auswertungen auf Loch-Ebene.

JSON in einer Spalte: einfacher beim Speichern, flexibler, aber schlechter für SQL-Abfragen.

9/18 feste Spalten plus Metadaten: sinnvoll, wenn das Schema stabil bleibt.

Für Golfergebnisse sind 18 einzelne Felder oft am praktischsten, wenn du später statistisch auswerten willst.

Separate Mapping-Funktion
Dann schreibst du in einem neuen Package eine Funktion, die aus InputData ein SqlData erzeugt:

package sqldata

import (
	"time"

	"github.com/lutzpeschlow/html_golang_sqlite/objects"
)

func PrepareSQLData(in *objects.InputData, date time.Time) objects.SqlData {
	return objects.SqlData{
		Date:      date,
		Option2:   in.Option2,
		Option3:   in.Option3,
		Option4:   in.Option4,
		Option5:   in.Option5,
		Score1:    in.Scores[0],
		Score2:    in.Scores[1],
		Score3:    in.Scores[2],
		Score4:    in.Scores[3],
		Score5:    in.Scores[4],
		Score6:    in.Scores[5],
		Score7:    in.Scores[6],
		Score8:    in.Scores[7],
		Score9:    in.Scores[8],
		Score10:   in.Scores[9],
		Score11:   in.Scores[10],
		Score12:   in.Scores[11],
		Score13:   in.Scores[12],
		Score14:   in.Scores[13],
		Score15:   in.Scores[14],
		Score16:   in.Scores[15],
		Score17:   in.Scores[16],
		Score18:   in.Scores[17],

Insert-Funktion
Die zweite Funktion schreibt dann die Datenbank. Mit database/sql sieht das ungefähr so aus:

go
package sqldata

import (
	"database/sql"
	"fmt"

	"github.com/lutzpeschlow/html_golang_sqlite/objects"
)

func InsertSQLData(db *sql.DB, s objects.SqlData) (int64, error) {
	query := `
		INSERT INTO rounds (
			date, option2, option3, option4, option5,
			score1, score2, score3, score4, score5, score6, score7, score8, score9,
			score10, score11, score12, score13, score14, score15, score16, score17, score18,
			created_at
		) VALUES (?, ?, ?, ?, ?,
		          ?, ?, ?, ?, ?, ?, ?, ?, ?,
		          ?, ?, ?, ?, ?, ?, ?, ?, ?,
		          ?)
	`

	res, err := db.Exec(
		query,
		s.Date, s.Option2, s.Option3, s.Option4, s.Option5,
		s.Score1, s.Score2, s.Score3, s.Score4, s.Score5, s.Score6, s.Score7, s.Score8, s.Score9,
		s.Score10, s.Score11, s.Score12, s.Score13, s.Score14, s.Score15, s.Score16, s.Score17, s.Score18,
		s.CreatedAt,
	)
	if err != nil {
		return 0, fmt.Errorf("insert sql data: %w", err)
	}
	return res.LastInsertId()
}
SQLite nutzt in database/sql normalerweise ? als Platzhalter.
